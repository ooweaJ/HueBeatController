# LedFx 원본 엔진 통합 실험

## 기준 버전과 보존

- 실험 브랜치: experiment/ledfx-engine
- 기존 기준: main / 77752d9
- 기존 Hue 재생·연출 코드는 기준 버전으로 보존한다.
- Git에서 제외된 data/의 음원·분석·설정은 브랜치 전환으로 복원되지 않는다. 새 엔진은 기존 분석 파일을 자동 변환하거나 덮어쓰지 않고 별도 결과 경로를 사용해야 한다.
- 기존 엔진과의 비교가 끝나기 전 main에 병합하지 않는다.

## 목표

LedFx 원본 분석과 효과 실행 경로를 함께 재사용하고, 동일 출력을 웹 모의 전구와 Hue Entertainment에 전달한다. 특정 곡에 맞춘 자체 임계값이나 클라이맥스 규칙을 추가하지 않는다.

## 구현 순서

1. LedFx 버전/커밋, 라이선스, Windows 실행 의존성과 출력 인터페이스 확인.
2. 원본 엔진을 독립 실행하고 지원 효과를 실제 오디오 입력으로 동작시킨다.
3. 원본 RGB 프레임을 받아 웹에서 표시하는 어댑터를 구현한다. 기존 분석 JSON을 원본 엔진 데이터처럼 대체 공급하지 않는다.
4. 같은 프레임을 A/B 동일 순번 쌍으로 매핑해 Hue Entertainment에 전달한다.
5. 여러 곡에서 원본 출력과 어댑터 출력의 동등성, 타이밍, 장르별 반응을 검증한다.
6. 파일 재생/사전 렌더링 및 분석 결과 보관은 원본 엔진이 지원하는 방식과 재현성을 확인한 뒤 연결한다.

## 검증 기준

- 원본 효과가 생성한 색상·밝기 관계를 전달 과정에서 임의로 바꾸지 않는다.
- 곡마다 임계값을 손으로 조정하지 않고 비교한다.
- 음악적 만족도와 원본 엔진 재현 여부는 각각 기록한다.
- 실시간 오디오 반응과 곡 전체의 공연 구성은 별개 기능이다. 자동 구간 연출은 아직 구현 범위에 포함하지 않는다.
- 실제 음원/설정/인증키는 커밋하지 않는다.
