# HueBeat 피아노 키오스크

배포 파일은 `distribution/kiosk/HueBeatKiosk.zip` 하나입니다. 소등과 은은한 점등은 같은 프로그램의 설정으로 전환합니다. GitHub에서 ZIP 파일을 열고 **Download raw file**로 내려받으세요.

## 실행 및 기존 설정 가져오기

1. 기존 키오스크와 HueBeat 서버를 종료합니다. 키오스크 종료 단축키는 **Ctrl+Shift+Q**입니다.
2. ZIP 전체를 새 폴더에 압축 해제합니다.
3. 기존 장비 설정을 유지하려면 예전 폴더의 `server/data`를 새 `HueBeatKiosk/server/data` 위치에 복사합니다. 처음 설치하면 웹 운영 화면에서 Bridge 인증, Entertainment 영역, 피아노 음계와 출력 허용, 상시 미디어아트를 설정합니다.
4. `HueBeatKiosk/HueBeatKiosk.exe`를 실행합니다. 웹 운영 화면은 같은 PC의 `http://localhost:5188/`에서 엽니다.

ZIP에는 인증키·현장 장비 설정·음원이 포함되어 있지 않습니다. 프로그램은 테두리 없는 전체 화면 창으로 실행되며, 내부 서버가 함께 실행됩니다. 이미 실행 중인 서버가 있으면 그 서버에 연결하므로 교체할 때 기존 서버도 종료해야 새 웹 파일을 사용합니다.

## 소등 / 은은한 점등 바꾸기

수정할 파일은 **압축을 푼 폴더의 `HueBeatKiosk/kiosk-settings.json`**입니다. `HueBeatKiosk.exe` 바로 옆에 있고, `server/data` 안의 파일이 아닙니다.

```json
{
  "pianoBaseBrightnessPercent": 0
}
```

| 값 | 피아노 연주 화면에서 건반을 누르지 않을 때 |
| --- | --- |
| `0` (배포 기본값) | 전구 완전 소등 |
| `8` | 매핑된 전구가 각 음계색으로 8% 밝기 유지 |

메모장으로 숫자만 바꾸고 저장한 뒤 **EXE를 종료하고 다시 실행**하세요. 0~100의 정수를 사용할 수 있고, 은은한 점등은 5~10부터 현장에서 비교하면 됩니다. 밝기가 높을수록 건반을 눌렀을 때와의 차이는 줄어듭니다.

두 설정 모두 건반을 누르면 해당 음의 전구가 100%로 밝아지고, 손을 떼면 짧게 감쇠해 설정한 기본 밝기로 돌아옵니다. 음계를 지정하지 않은 전구는 소등합니다. 소리 음량과 전구별 음계는 기존 웹 운영 화면에서 설정합니다. 일반 브라우저 피아노 화면에는 이 EXE 설정이 적용되지 않습니다.

## 자동 복귀 및 터치

- 연주 시작 또는 마지막 건반을 놓은 뒤 **60초 동안 입력이 없으면** 사용 종료와 같은 처리를 거쳐 시작 화면과 저장된 상시 미디어아트로 복귀합니다. 건반을 누르고 있는 동안에는 종료하지 않습니다.
- 여러 손가락의 동시 연주와 건반 사이 슬라이드를 지원합니다. EXE 내부의 확대·축소와 스와이프 탐색은 차단하고 전체 화면 버튼은 숨깁니다.
- Windows 자체의 3·4손가락 창 전환 제스처는 별도 노트북 설정이며 이 EXE가 변경하지 않습니다.

## 배포본 다시 만들기

저장소 루트에서 .NET 10 Windows Desktop SDK와 Python으로 실행합니다. 기존 ZIP의 런타임을 재사용하고, 호스트 및 피아노 웹 파일을 갱신합니다. 서버 본체를 새로 게시하는 명령은 아닙니다.

```powershell
python tools/kiosk/package.py --base-zip distribution/kiosk/HueBeatKiosk.zip
```

검증된 결과로 같은 ZIP을 교체합니다. 다른 경로에 만들려면 `--output .build/HueBeatKiosk.zip`, 초기 밝기를 바꾸려면 `--piano-base-brightness 8`을 추가하세요. 현장 `server/data`는 패키징하지 않습니다.
