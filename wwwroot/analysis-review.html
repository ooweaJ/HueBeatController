02 / VIRTUAL LIGHTS

한 쌍 점등 + 클라이맥스 색 전환

일반 구간에서는 실제 소리 시작과 저음 상승이 함께 검출된 타격만 현재 한 쌍을 펀치합니다. 클라이맥스에서는 전체를 점등하고 일반 박자로 밝기를 펀치하며, 마디 첫 박자에서만 색을 바꿉니다.

마디 첫 박자를 선택하고 재생하세요.

클라이맥스 색은 코랄 → 청록 → 골드 → 보라를 순환합니다. 일반 구간에서는 박자선만으로 전구를 켜지 않습니다. 다른 후보 탭에서는 모의 점등이 꺼집니다.

현재 소리 분석과 조명 동작 방식 보기
  1. 약 11.6ms마다: 전체 음량, 저음·중음·고음 에너지, 소리 시작 강도를 읽습니다.
  2. 일반 구간의 타격: 고정 박자표와 분리해 실제 소리 시작·저음 급상승의 국소 피크만 고릅니다. 감지된 타격 하나가 현재 A/B 한 쌍을 켰다가 감쇠시킵니다.
  3. 클라이맥스의 일반 박자: 전체 점등 상태에서 밝기만 펀치합니다. 마디 첫 박자는 색 전환의 기준점으로만 사용합니다.
  4. 자동 클라이맥스: 지속 에너지와 대역 충만도·타격 강도·박자 밀도를 합칩니다. 늦게 잡힌 진입은 이미 강해진 앞쪽 마디를 최대 두 마디 되짚고, 종료는 고역과 타격 에너지가 함께 무너지는 첫 마디로 당깁니다.

파형 높이 하나만으로 결정하지 않으며, 자동 후보는 편집 가능한 초안입니다. 실제 Hue 출력은 아직 하지 않습니다.

자동 클라이맥스 구간 검토

처음에는 분석 데이터로 만든 자동 후보가 표시됩니다. 먼저 재생해 보고 경계가 틀릴 때만 삭제하거나 시작·끝을 직접 표시하세요. 입력 단위는 초입니다(1분 = 60초).

연출 구간을 불러오는 중…

곡·분석 버전별로 별도 보관합니다. 재분석해도 이전 연출은 남지만 새 분석 버전에 자동 복사되지는 않습니다.

짧은 간격 후보 검토

주변 간격에 비해 가까운 후보를 표시한 것입니다. 오류 확정이 아니며 자동 삭제하지 않습니다.

판단 방법 · 알아둘 점

소리 시작: ‘뚠!’과 클릭이 맞는지, 한 소리에 클릭이 여러 번 나거나 빠지는지 확인합니다. 보컬·장식음도 검출될 수 있고, 모두 조명에 사용할 것은 아닙니다.

박자: 발로 박자를 셀 때 클릭이 맞는지 확인합니다. 실제 타격음이 없는 박에도 클릭이 날 수 있습니다. 개수가 많다고 더 정확한 것은 아닙니다.

그려진 곡 전체 파형은 화면 해상도에 맞춰 축약됩니다. 실제 클릭은 축약하지 않은 후보 시각을 사용합니다. 브라우저 화면 표시에는 별도 지연이 있을 수 있으므로 소리끼리 비교하세요.

헤드폰 또는 낮은 음량으로 시작하세요. 현재 저장하는 값은 수동 클라이맥스 구간뿐이며 분석 후보와 실제 Hue 설정은 바꾸지 않습니다.
