02 / VIRTUAL LIGHTS

8마디 누적 점등 + 전체 펀치

A 8개 + B 8개가 기본 배치입니다. 도입·일반은 마디 첫 박자마다 A1+B1부터 한 쌍씩 더 켜고 유지합니다. 8번째 마디의 3박에 소등, 4박에 전체 펀치 후 다시 소등합니다. 다음 순환마다 정순·역순·중앙→바깥·바깥→중앙으로 바뀌며 단색에서 두 색, 여러 색으로 확장합니다.

마디 첫 박자를 선택하고 재생하세요.

무음 마디·클라이맥스에서 누적 순환을 중단하고 이후 마디부터 다시 채웁니다. 다른 후보 탭에서는 모의 점등이 꺼집니다. 8쌍보다 작은 모의 배치도 8마디 길이는 유지합니다.

현재 소리 분석과 조명 동작 방식 보기
  1. 1~7마디: 마디 첫 박자에 다음 좌우 쌍을 추가합니다. 이미 켜진 쌍은 배정된 색을 유지하고 전체 밝기는 약 35.5%에서 60%까지 올라갑니다.
  2. 8마디: 1박에 전체 점등, 2박까지 유지, 3박에 빠르게 감쇠·암전, 4박에 현재 색으로 전체 펀치 후 다음 마디 전 소등합니다.
  3. 다음 순환: 다음 마디 첫 박자에 순서와 색 구성을 바꿔 다시 누적합니다.
  4. 진입 준비: 클라이맥스 직전 최대 4마디 동안 남은 쌍을 채우고 밝기를 올립니다. 마지막 준비 마디의 첫 박부터 약 0.2초 동안 부드럽게 소등하고 클라이맥스 시작까지 암전을 유지합니다. 클라이맥스 시작에 새 색과 전체 펀치로 진입합니다.
  5. 클라이맥스: 전체 점등을 유지하며 4마디씩 단색·두 색·여러 색으로 확장합니다. 2마디씩 전체 펀치와 홀짝 교대 펀치를 번갈아 사용합니다.
  6. 타이밍: 4/4 마디 안의 실제 Beat를 사용합니다. 내부 Beat가 3개가 아니면 해당 마디 길이의 1/2·3/4 지점으로 마무리 시각을 정하고 상태에 표시합니다.

파형 높이 하나만으로 결정하지 않으며, 자동 후보는 편집 가능한 초안입니다. 실제 Hue 출력은 아직 하지 않습니다.

자동 클라이맥스 구간 검토

처음에는 분석 데이터로 만든 자동 후보가 표시됩니다. 먼저 재생해 보고 경계가 틀릴 때만 삭제하거나 시작·끝을 직접 표시하세요. 입력 단위는 초입니다(1분 = 60초).

판단 방법 · 알아둘 점

소리 시작: ‘뚠!’과 클릭이 맞는지, 한 소리에 클릭이 여러 번 나거나 빠지는지 확인합니다. 보컬·장식음도 검출될 수 있고, 모두 조명에 사용할 것은 아닙니다.

박자: 발로 박자를 셀 때 클릭이 맞는지 확인합니다. 실제 타격음이 없는 박에도 클릭이 날 수 있습니다. 개수가 많다고 더 정확한 것은 아닙니다.

그려진 곡 전체 파형은 화면 해상도에 맞춰 축약됩니다. 실제 클릭은 축약하지 않은 후보 시각을 사용합니다. 브라우저 화면 표시에는 별도 지연이 있을 수 있으므로 소리끼리 비교하세요.

헤드폰 또는 낮은 음량으로 시작하세요. 현재 저장하는 값은 수동 클라이맥스 구간뿐이며 분석 후보와 실제 Hue 설정은 바꾸지 않습니다.
